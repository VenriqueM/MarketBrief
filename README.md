# MarketBrief

A responsive financial news and market intelligence dashboard built with React, TypeScript, Vite, and plain CSS.

## Current data status

- News uses hourly refreshed Government of Canada RSS/Atom feeds generated by GitHub Actions, so it works while your Macs are off. It includes national news, business/finance, science and innovation, and Statistics Canada releases. It is not a broad US or global newswire.
- Headlines and feed descriptions are copied with attribution and links to original articles under the Government of Canada non-commercial reproduction terms. MarketBrief does not claim government affiliation or endorsement.
- If the latest feed artifact is unavailable or empty, the application switches to clearly labelled fictional demo stories.
- An official TradingView Market Data widget provides the S&P 500, Nasdaq Composite, S&P/TSX Composite, USD/CAD, gold, crude oil, and additional global indices. TradingView controls its quote updates and any source timestamps; equity data may be delayed, and freshness varies by market/instrument. MarketBrief does not extract or restate the widget’s quotes as its own live data.
- TradingView Top Stories and Economic Calendar widgets provide a compact market-news view and upcoming events. They load directly from TradingView in each visitor’s browser and include TradingView attribution.
- MarketBrief separately attempts the Bank of Canada Valet daily USD/CAD reference series. When returned, the rate date and source are labelled. It is not an intraday trading quote. If that request fails, no Bank of Canada value is shown; TradingView’s USD/CAD widget is separate.
- If TradingView’s market widget script fails to load, the previous market cards appear as clearly labelled **DEMO · NOT LIVE** fallback values.
- See [docs/SOURCES.md](docs/SOURCES.md) for source access and licensing notes.

## Features

- Search, category filtering, and newest-first sorting across six news topics.
- Bookmarks, private notes, and a starter watchlist saved in browser localStorage.
- Compact TradingView market, market-news, and economic-calendar widgets with links to full TradingView charting.
- Typed news and market provider interfaces, source validation, source labels, loading/error states, and demo fallback.
- Responsive layout, keyboard navigation, visible focus indicators, and empty states.

Local preferences stay in the browser profile on the current device. They do not automatically sync to a phone, tablet, or another computer. GitHub Pages serves the static frontend while your Macs are off. Sync, accounts, and private server-side data would require a backend service.

## Requirements and local development

- Node.js 24 LTS (npm is included)
- Git

```sh
npm install
npm run dev
```

`npm run dev` first refreshes the public news feeds into an ignored local file, then starts Vite. If the feeds cannot be reached, the app uses its clearly labelled fictional demo stories. Open the local URL printed by Vite, usually `http://localhost:5173/`.

## Build and preview

```sh
npm run build
npm run preview
```

The production files go to `dist/`. `npm run build` runs TypeScript project checks and Vite bundling. No separate automated test suite is configured.

## Deployment

The `.github/workflows/deploy.yml` workflow builds and publishes the site on GitHub-hosted runners; no personal computer serves the production site. It refreshes official news feeds when deploying and on an hourly schedule. The Vite base path is set for `https://venriquem.github.io/MarketBrief/` during the Pages build. GitHub Pages must use **GitHub Actions** as its deployment source.

The static site contains no private API credentials. Never add a secret to a `VITE_*` variable: Vite embeds frontend environment variables into public browser assets. Providers needing private keys require a server-side design and separate review before adding infrastructure.

The TradingView widgets load from TradingView’s servers at runtime, while the frontend itself remains on GitHub Pages. Widgets will not show if a visitor’s browser/network blocks TradingView. TradingView says its financial widgets may show delayed equity data and do not provide a data API or export; the widgets themselves display any timing/provider detail available for a symbol. Forex and crypto widget data may be real time, but MarketBrief does not describe the entire widget as live. See [docs/SOURCES.md](docs/SOURCES.md) for details.
